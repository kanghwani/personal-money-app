# UX 개편 설계 — 입력 방식 + 홈 대시보드 + 코지 베이지 테마

작성일: 2026-06-08

## 목적
가계부 앱(돈 정리)의 (1) 입력 방식, (2) 홈 대시보드 구성, (3) 색·테마를 개편한다.
브레인스토밍에서 목업으로 각 항목을 확정했다.

## 확정 결정 (목업으로 승인됨)

### 1. 테마 — 코지 베이지 (라이트)
- 다크 차콜 → **라이트 코지 베이지**로 전환. 앱 전체 적용.
- 팔레트(대략): 배경 크림 `#f1e9db`, 카드 `#fbf7ef`, 텍스트 `#352b1f`/`#4a3f30`, 보조텍스트 `#8a7a64`,
  경계선 `rgba(120,90,50,.15)`, **주 액센트 테라코타 `#c9794f`**, 보조 세이지 `#7e9b6f`, 골드 `#d6a85e`, 보라 `#9a7bb0`.
- 그림자: 따뜻한 톤의 부드러운 그림자.
- PWA 메타(manifest `theme_color`/`background_color`, index.html status-bar)도 라이트에 맞춰 갱신.

### 2. 홈 대시보드 (위→아래)
- **카테고리 구성 링**: 가운데 = 이번 달 실지출 총액, 보조문구 = 전월 대비 ±%. 고리 = 카테고리별 색 분할(금액 비중).
- **카테고리 순위 리스트**: 상위 5개 + 기타 (이름·색점·금액·%).
- **고정비 · 변동비 분해**: 가로 split 막대 + 두 금액.
- 홈에서 제거: 예산 카드(예산 미사용), 4-메트릭 카드 중 순자산·투자, **월별 흐름 차트**.

### 3. 입력 방식 — 하단 고정 스마트바
- 화면 **하단 고정**(탭 네비 바로 위)에 입력 영역. 기존 상단 QuickEntry 제거.
- 구성: **빠른칩 행** + **자연어 입력 필드**(전송 버튼).
- **빠른칩 한번 탭 = 즉시 기록**: 칩(예: ☕커피)을 탭하면 학습된 기본값(금액·카테고리·결제수단)으로 거래 즉시 추가 + **되돌리기 토스트**(수 초).
- **자동 학습 칩**: 최근 자주 입력한 항목을 기반으로 칩을 자동 구성(고정 설정 없음).
- **자연어 필드**: 기존 `parseQuickEntry`로 "오늘 점심 9000 카드" 같은 입력 파싱(현행 유지, 위치/디자인만 변경).

### 4. 탭 재배치
- **인사이트 탭**: 월별 흐름(AreaChart)을 이리로 이동.
- **자산 탭**: 순자산·투자·자산 관련 지표(기존 위치 유지/정리).

## 아키텍처 / 접근

### 테마 (대부분 CSS 변수 교체)
- `src/index.css`의 `:root` 변수(`--bg, --surface, --surface-solid, --ink, --muted, --line, --accent-tan, --green, --danger, --blue, --amber, --soft-shadow`)를 코지 베이지 값으로 재정의.
- 라이트 모드에서 깨지는 다크 전용 스타일(차트 그라데이션, glassmorphism 반투명, 일부 하드코딩 색)을 점검·수정.
- `--accent-tan`을 테라코타로 바꾸면 차트(recharts가 `var(--accent-tan)` 사용)·버튼·칩이 일괄 적용됨.

### 입력 — 하단 고정 바 컴포넌트
- 신규 `BottomInputBar` 컴포넌트(또는 App 내 섹션): 빠른칩 행 + 자연어 필드. `position: fixed` 하단, 탭 네비 위.
- 빠른칩 데이터: 신규 순수함수 `deriveQuickChips(transactions): QuickChip[]` — 최근 거래에서 (카테고리/메모 키워드)별 빈도 상위 N개를 뽑고, 각 칩의 기본 금액(최빈/최근)·카테고리·소분류·결제수단을 산출.
- 한번 탭 로직: 칩 → `setStore`로 거래 추가(기본값) → 되돌리기 토스트 표시 → 되돌리면 해당 거래 제거.
- 자연어: 기존 `parseQuickEntry`/`applyQuickInput` 재사용.
- 본문 컨테이너에 하단 패딩(입력바+네비 높이만큼) 추가해 가림 방지.

### 홈 대시보드 재구성
- 신규/수정 컴포넌트:
  - `CategoryRing` — 카테고리 구성 도넛(conic-gradient 또는 recharts Pie) + 중앙 실지출/전월대비.
  - `CategoryRankList` — 상위 5 + 기타.
  - `FixedVariableBar` — 고정/변동 split(기존 `FixedVariablePanel` 활용/리디자인).
- 전월 대비: `buildSummary`에 `previousMonth`가 이미 있음 → 증감% 계산.
- `Dashboard`에서 예산 카드·순자산/투자 메트릭·월별흐름 제거.

### 인사이트 탭
- 월별 흐름 AreaChart(현재 Dashboard의 차트 블록)를 `InsightsView`로 이동. `summary.monthlyTrend` 그대로 사용.

## 데이터/로직 영향
- `summary`는 이미 merged 거래 기반(원장 병합 완료). 카테고리 링/순위/고정변동/전월대비 모두 `summary`에서 파생.
- 빠른칩 자동학습은 merged 거래(`mergedTransactions`)에서 파생.

## 범위 / 분해
- 큰 개편이라 구현 계획에서 단계 분해: (A) 테마 변수 교체 + 라이트 점검, (B) 홈 대시보드 재구성(링/순위/고정변동), (C) 월별흐름 인사이트 이동, (D) 하단 입력바 + 빠른칩 자동학습 + 즉시기록/되돌리기.
- 각 단계는 독립적으로 빌드·확인 가능하도록.

## 테스트 전략
- 순수함수 단위테스트(Vitest): `deriveQuickChips`(빈도/기본값 산출), 전월대비% 계산 헬퍼, 카테고리 비중 계산.
- 빌드(tsc) 통과 + 기존 테스트 회귀 없음.
- 통합 수동: 배포 후 브라우저로 홈/입력/테마/탭 확인(Claude in Chrome).

## 범위 밖 (YAGNI / 별도)
- 음성 입력, 영수증 OCR(이번 입력 개편에서 제외 — 자연어+원탭만).
- 예산 기능(미사용 확인됨).
- 자산/투자 데이터의 시트 연동(이번 범위 아님; 현재 store 기반 유지).
- 다크/라이트 토글(라이트 단일로 진행).

## 기존 코드 영향
- `src/index.css`: 팔레트 변수 재정의(+ 라이트 보정).
- `src/App.tsx`: Dashboard 재구성, 하단 입력바 신설(상단 QuickEntry 제거), InsightsView에 월별흐름 추가, 빠른칩 로직.
- `src/App.css`: 신규/변경 컴포넌트 스타일.
- 신규 `src/quickChips.ts`(또는 sync/ 외 util): `deriveQuickChips` 순수함수 + 테스트.
- `index.html`/`public/manifest.json`: 라이트 테마 메타.
