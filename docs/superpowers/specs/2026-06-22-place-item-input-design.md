# 장소/물건 입력 모델 설계 (대분류·소분류 대신 장소+물건)

작성일: 2026-06-22

## 목적
입력·표시·수정을 사용자가 떠올리기 쉬운 **장소(어디서) + 물건(무엇을)** 으로 바꾼다. 예: `5000 다이소 청소용품 하나카드` → 장소=다이소, 물건=청소용품. 대분류/소분류는 장소로부터 **자동 유추**하여 기존 리포트·차트·인사이트를 그대로 유지한다.

## 핵심 결정 (브레인스토밍 승인)
- **저장 구조 불변:** 지금도 금액·결제수단·날짜를 뺀 나머지가 `내역(memo)`에 저장되고 그 텍스트로 자동분류된다. 즉 "장소 물건"이 이미 memo에 들어간다. → **장소/물건은 저장이 아니라 해석·표시·수정 레이어.**
- **장소 = memo의 첫 단어, 물건 = 나머지.** 한 단어면 장소만(물건 빈값).
- **카테고리(대/소분류)는 장소 기반 자동** (기존 `classify` + 학습규칙 그대로). 보강만.
- **GAS·시트·리포트 변경 없음.** 시리 입력도 그대로(memo 합쳐 저장 → 앱이 분리 표시). → GAS 재배포 불필요, 앱(Vercel)만 수정.
- 마이그레이션 불필요(기존 memo가 그대로 "장소 물건"으로 해석됨).
- **범위 밖:** 대시보드 "장소 TOP" 차트(추후), 장소/물건 별도 컬럼 신설.

## 컴포넌트 설계

### 1. 순수 분리 함수 (TDD) — `src/dashboardLogic.ts`
- `splitPlaceItem(memo: string): { place: string; item: string }`
  - memo를 trim → 첫 공백 기준으로 분리. 첫 토큰=place, 나머지=item(없으면 '').
  - 예: `"다이소 청소용품"` → `{place:'다이소', item:'청소용품'}`; `"스타벅스"` → `{place:'스타벅스', item:''}`; `""` → `{place:'', item:''}`.
- `joinPlaceItem(place: string, item: string): string`
  - `place`와 `item`을 공백으로 합쳐 trim. 빈 값 안전 처리. 수정 저장 시 memo 생성에 사용.
- Vitest 단위테스트: 두 단어, 한 단어, 빈 입력, 앞뒤 공백, 물건에 공백 여러 개.

### 2. 거래 수정 시트 — `src/App.tsx` `TransactionEditSheet`
- 기존 `내역` input 한 칸 → **`장소`(place) + `물건`(item)** 두 칸으로 교체.
  - 진입 시 `splitPlaceItem(tx.memo)`로 초기값 채움.
  - 저장 시 `memo = joinPlaceItem(place, item)`로 합쳐 `onSave({...draft, memo})`.
- 대분류/소분류: **기본 접힘(자동값 표시)**, "분류 수정" 펼치기 토글로 노출(기존 datalist 자동완성 유지). 자동값은 현재 tx.category/subCategory(파서/학습이 채운 값).
- 결제수단·날짜·구분·고정변동·분담금: 그대로.

### 3. 거래 목록 표시 — `src/App.tsx` `Ledger` 행
- 제목(row-title): **장소 강조(굵게) + 물건**. `splitPlaceItem(memo)`로 분리해 `🏪 {place} · {item}` 형태(물건 없으면 장소만).
- 보조줄(row-meta): 날짜 · 자동카테고리(작게) · 결제수단. (기존과 유사, 카테고리는 보조 정보로)
- 카테고리 상세 시트(`CategoryDetailSheet`) 행도 동일하게 장소/물건 표시 적용.

### 4. 홈 입력 안내 — `src/App.tsx` `QuickEntry`
- placeholder를 `5000 다이소 청소용품 하나카드`로 변경(형식 유도). 파서 로직 변경 없음(memo가 곧 "장소 물건").

### 5. 장소 자동분류 보강 (데이터)
- 자주 쓰는 장소에 분류규칙을 미리 추가(앱 배포와 무관, `assignCategory` API로 시트 `v2_분류규칙`에 반영):
  다이소→생활/생활잡화, 올리브영→생활/뷰티미용, 코스트코·홈플러스·롯데마트·이마트·노브랜드·와마트·마켓컬리→식비/식자재, CU·GS25·세븐일레븐→식비/간편식, 스타벅스·컴포즈·메가커피(기존)·투썸·이디야·빽다방→식비/카페간식, 유니클로→쇼핑/의류 등.
- 앱 로컬 학습규칙(`learnedRules`)도 그대로 동작(교정 시 학습).

## 데이터 흐름
1. 입력 `5000 다이소 청소용품 하나카드` → 파서가 금액 5000·결제 하나카드 추출 → memo="다이소 청소용품" → classify로 카테고리 자동 → 원장 기록(appendLedger).
2. 목록: memo를 `splitPlaceItem` → "🏪 다이소 · 청소용품" 표시 + 자동 카테고리 보조.
3. 수정: 장소/물건 칸 편집 → `joinPlaceItem` → memo 갱신 → `editTransaction`(updateLedger).
4. 리포트/차트/인사이트: 카테고리 컬럼 그대로 사용(불변).

## 에러/엣지
- 한 단어 입력 → 장소만, 물건 빈값. 표시는 장소만.
- 기존 거래(memo 다양) → 첫 단어=장소로 자연 해석, 마이그레이션 없음.
- memo가 빈 거래(수입 "급여" 등) → place=급여, item=''. 정상.
- 장소가 분류규칙에 없으면 미분류 → 홈 인라인 교정 칩(기존 기능)으로 고치면 학습.

## 테스트 전략
- `splitPlaceItem`/`joinPlaceItem` Vitest 단위테스트.
- 수정 시트: 장소/물건 분리·합치기 왕복(편집→저장→memo 일치) 수동 확인.
- 배포 후 Chrome 실측: 입력→목록 장소/물건 표시, 수정 시트 장소/물건 편집, 자동카테고리 확인.

## 범위 밖

- 장소/물건 전용 시트 컬럼 신설(현재 memo로 충분).
- GAS/시트 스키마 변경.
