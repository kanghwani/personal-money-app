# 2026-09-21 유튜브 구독자 이벤트

## 왜 이렇게

- **RSS 를 버렸다.** 설계 전에 대상 채널 피드를 직접 쳐보니 십만양품·디에디트·기즈모 404, ITSub 500, UNDERkg·침착맨 200.
  채널 페이지가 `feeds/videos.xml?channel_id=` 링크를 광고하는데도 404 다. 원인은 못 찾았고 채널마다 달라서 소스로 못 쓴다.
  Data API 는 키만 있으면 되고 `playlistItems` 가 설명 전문을 준다(1단위/호출). 설계 첫 섹션 전에 확인해서 다행이었다.
- **GAS 를 안 건드렸다.** `action=health&type=<탭>` 이 아무 탭에나 `start|end|value|extra` 를 붙인다.
  `events` 탭에 상태 변화를 행으로 추가만 하고 마지막 행이 현재 상태. 수정 API 를 만들 필요가 없고 이력이 공짜다.
- **cron 없음.** 단축어가 `/api/events` 를 부르면 서버가 스캔·큐를 한 번에 한다. 트리거가 하나면 고장 지점도 하나.
  하루 빠져도 다음 날 최근 10개를 다시 보므로 잃는 게 없다.
- **미리알림 두 개.** 마감 전날 "[지원]", 발표일 "[결과]". 알림은 미리알림 앱이 담당하고 서버는 날짜만 준다.
  0건이면 반복이 안 돌아 조용하다 — 단축어 조건문은 변수 비교가 자주 깨져서 안 쓴다(건강 생성기의 교훈).
- **댓글은 손으로.** 자동 댓글은 계정 위험. 발췌를 `event_list` 가 돌려주면 클로드 앱이 그 자리에서 초안을 쓴다.
- **가계부는 인프라만.** 당첨금은 필요할 때 `ledger_add` 로. 코드 0.

- `@theedit` 은 빈 채널이었다. 검색 결과 HTML 의 `channelId` 는 못 믿고 채널 페이지 `externalId` 만 믿을 것.

## 09-22: 맥 알림은 단축어가 아니라 스크립트

- 사용자가 폰 안 쓰고 맥에서만 쓴다고 해서 launchd 로 매일 09:00 + 로그인 시 실행.
- 처음엔 같은 `eventsync` 단축어를 맥 단축어 앱에 넣고 `shortcuts run` 으로 돌렸는데, **미리알림에 기한·알림이 안 들어가고**
  80개 중 59개만 생겼다(지원 23·결과 36). 액션 파라미터 키(`WFAlertCustomTime`)를 확인할 방법이 없어(WorkflowKit 리소스에 정의 파일 없음)
  단축어를 버리고 AppleScript(JXA)로 직접 만들었다. `dueDate`·`remindMeDate` 를 넣으니 74개 전부 기한 포함으로 생겼다.
- JXA 를 `osascript -l JavaScript -` 로 stdin 에서 읽으면서 JSON 도 stdin 으로 넘겨 충돌했다. 스크립트는 파일, JSON 은 임시 파일 인자로.
- AppleScript `whose due date is missing value` 는 -1700 오류. 목록 자체가 우리 것뿐이라 통째로 지웠다.
- **감시 채널은 제목만 믿는다.** 사용자가 방금 응모한 정가거부 "이벤트 #14" 가 안 잡혔다 — 설명에 링크만 있고 구독·댓글이 없었다.
  직접 등록한 채널은 제목에 "이벤트"면 통과, 검색 결과는 그대로 엄격. 잡힌 뒤 "지원" 기록하고 [지원] 미리알림은 완료 처리.

  내 댓글에 채널 계정이 단 답글, 그 채널의 새 영상 설명. 이벤트당 3단위. 커뮤니티 게시글은 API 가 없다.

- 댓글 API 403(댓글 막힘)은 빈 배열로 삼키므로, 실제로 읽었는지 스캔 요약에 "결과 검사: 채널(댓글 N·새영상 M)" 을 남겼다.
  실경로 확인: 십만양품 옛 이벤트에 applied 를 붙여 돌려 "댓글 1·새영상 10" 을 봤다. 끝나고 lost 로 닫음.
- `vercel env add --value --yes` 가 값은 넣고도 프로세스가 안 끝난다. 다음엔 터미널에서 대화형으로.

## 09-27: 이벤트가 너무 많아졌다 → LLM 채점

일주일 돌리니 지원 대기 91건, 캘린더가 [지원]·[결과]로 뒤덮였다. 원인 둘.
1. **[결과] 알림을 응모하지도 않은 이벤트에 다 만들고 있었다.** 응모한 것만 만들면 37 → 2.
2. [지원]을 가치·경쟁률 상관없이 전부 만들었다.

**금액 정규식을 먼저 시도했고 버렸다.** 91건 중 14건만 금액이 잡혔고, 그마저 "3만원으로 쇼핑", "180만원까지 책"
처럼 **영상 내용의 가격**을 경품으로 집었다. 경품은 대개 "에어다운 압축 파우치"처럼 이름뿐이라 가치를 알려면
그게 뭔지 알아야 한다 — 규칙으로 할 수 없는 일이다.

그래서 맥 스크립트가 `claude -p --model haiku` 로 채점한다(91건 3분, ~$0.04). 경품·1인분 가치·당첨자 수와
**응모가치 1~5**(기대값 = 가치×당첨자÷max(댓글,20) 구간). 결과를 `grade` 행으로 시트에 남겨 한 번만 채점한다.
분포: 1점 55 · 2점 19 · 3점 10 · 4점 5 · 5점 1. 미리알림은 4점 이상만 → **8개**(지원 6 + 결과 2).
5점은 "화장품 200개 200명"(포푼젤), 4점은 LG 이어폰 5명·쿠지 100만원 1명 같은 것들이라 납득할 만했다.

- 시트가 진실이라 미리알림은 언제든 지우고 `ALL=1` 로 다시 만들 수 있다. 기준을 바꾸려면 `WORTH_MIN=3`.
- 미리알림 대량 삭제: AppleScript `delete r` 반복은 46개에 10분+, JXA `r.delete()` 는 아예 없는 함수.
  **목록을 통째로 지우고 다시 만드는 게 2초.** 완료 표시는 서버에 있으니 잃을 게 없다.
- 단축어(`.sh`)를 버리고 파이썬 하나로 합쳤다. 채점·필터·미리알림이 한 파일에 있어야 흐름이 읽힌다.
