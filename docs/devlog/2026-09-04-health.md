## 결정과 근거

**분석은 서버, 표현만 AI.** 준비도·주간 변경·진급 판정을 전부 결정론적 규칙으로 계산하고 선택지를 좁혔다.
LLM에게 센서 데이터 해석을 맡기면 그럴듯한 인과를 지어낸다는 근거가 있었고, 실제로 초기 프롬프트 방식이
그랬다. 다음 주 변경은 여섯 선택지 중 하나만 고르게 했다.

**발견은 문턱을 못 넘으면 버린다.** 표본 30, 효과크기 0.3. 계산해놓고 버린 것이 둘 있다.
취침 시각과 안정심박(r=-0.19, 문헌과 반대 방향), 총수면과 다음날 HRV(r=-0.09). 살린 것은 셋.
운동 다음날 HRV +4.1ms(d=0.37), 금요일 수면 최소(화 7.4h vs 금 6.3h), VO2max 1년 대비 -2.6.

**표면은 셋으로 고정.** 아침 알림(결정) / 웹앱(기록·조회) / 클로드 대화(질문). 노션은 다시 읽을 글만.
볼 곳이 늘면 아무 데도 안 본다는 게 자가추적 연구의 1·2위 이탈 원인이었다.

**닌텐도·플스 자산은 쓰지 않았다.** 배포되는 페이지라 상표·캐릭터를 넣으면 침해다.
휴대용 게임기 UI 문법으로 원본 도트 마스코트를 그렸다.

## 실패와 헛디딤

기록해두는 이유는 같은 데서 두 번 잃지 않기 위해서다.

**단축어 (하루의 절반을 여기서 썼다)**
- 날짜 필터 단위 코드를 틀림(16384 → 16). 필터가 무시돼 9년치를 전부 훑고 URL 한도에서 죽었다
- 텍스트형 파라미터에 첨부 직렬화를 씀. 액션은 멀쩡히 보이는데 실행하면 빈 값이 넘어갔다.
  `WFTextTokenString` 이어야 한다. 이걸 찾는 데 진단용 서명본을 네 번 만들었다
- `Workouts`·`Workout` 둘 다 없는 타입. 애플 기본 액션에는 운동 세션 읽기가 아예 없었다.
  무료 Actions 앱의 `Find Workout`(AppIntent)으로 해결
- 걸음이 워치+폰 이중 합산(건강 앱 8,935 vs 단축어 17,399). 백필 전용으로 돌림
- 일 그룹화 블록에 샘플 제한을 걸어 칼로리 합계가 잘림. 제한은 그룹화 **전에** 적용된다

**배포·인증**
- Vercel은 `api/*.ts` 를 전부 함수로 잡는다. `api/health.test.ts` 가 함수가 돼 빌드가 깨졌다 → `_` 접두어
- `Array.prototype.at` 으로 빌드가 깨졌다. Vercel 기본 lib 타깃이 낮다 → `--target es2021` 로 사전 검증
- `vercel env pull` 이 Secret 타입을 안 준다. 두 번 헤맸다. `SYNC_TOKEN` 통로로 우회
- curl이 `APP_SECRET` 의 `[` 를 range로 해석해 조용히 실패했다 → `-g`

**계정**
- 가계부 시트·GAS는 kanggokim91 소유인데 클로드 Drive 커넥터는 zzangh2다.
  zzangh2에 만든 건강 시트를 GAS가 못 열었다. 시트를 GAS가 자기 계정에 만들게 바꿨다

**로직**
- 짧은 수영 세션(49m)이 49km로 계산됐다. 거리 단위를 종목으로 판단해야 했다
- 진급 게이트가 계획보다 빡셌다. 계획은 "네거티브 5초 3~4회"를 시키는데 게이트는 "8초 5세트"를 요구해
  계획대로 해도 영원히 진급하지 않는 상태였다. **게이트 숫자는 계획 문구와 같아야 한다**
- 러닝 게이트가 "3주 정체"를 주장하면서 정체를 확인하지 않았다. 방금 늘렸어도 또 늘리라고 했을 것이다.
  리서치의 1위 부상 요인(단일 세션 급증)과 정반대로 동작할 수 있었다

**도구 스키마 (사용자가 잡아준 것)**
- `coach_week` 핸들러는 `args.week` 를 읽는데 `inputSchema` 에 올리지 않았다. 툴을 사이에 끼워 넣으면서
  문자열 치환 앵커가 깨져 조용히 무시됐고, 나는 확인하지 않았다. 설명만 먼저 바뀌어 더 헷갈렸다
- 그 뒤 만든 검증 스크립트의 정규식 파서가 오탐을 냈다(`ledger_add` 가 뒤 툴들의 키를 흡수).
  정규식을 버리고 `TOOLS` 를 직접 import 하는 방식으로 바꿨다
- `deploy:prod` 의 전후 비교는 "다른 경로로 이미 배포된 경우" 조용해진다. 기준을 실서버가 아니라
  저장소(`api/tools.lock.json`)에 두어야 배포 경로·기기와 무관해진다

**화면**
- 1비트 레트로 첫 판에서 주사선을 글자 위에 덮어 가독성이 떨어졌다. 배경으로 내렸다
- 보조 텍스트가 9~11px이었다. 11.5px 이상으로 올렸다
- 수면 단계 요약을 폰에서 4칸으로 깔아 글자가 겹쳤다. 2칸으로
