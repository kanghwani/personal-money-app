# 2026-10-10 ~ 10-11 · 정리: 돈에 관한 것만, 한 레포, 커넥터 없이

한 레포에 시스템이 다섯 개(가계부·건강 코치·약속 코치·유튜브 이벤트·스페인어)였다. 돈에 관한 두 개만 남겼다.

## 결정과 근거

- **건강 코치·약속 코치·스페인어 제거.** 건강은 iOS 기본 기능으로 대체, 약속 코치는 건강 위에 얹힌 것, 스페인어는 미사용.
  GAS 의 `health*` 함수는 남겼다 — 이름만 건강이고 이벤트 탭이 범용 탭 저장소로 쓴다. 지우면 GAS 재배포가 필요했다.
- **이벤트 레포 분리를 해 봤다가 되돌렸다.** 코드로는 거의 떨어져 있었지만(공유는 `_gas.ts` 하나), 분리하니
  Vercel 프로젝트·커넥터·환경변수·launchd 경로가 둘이 됐다. "경품도 돈"이라 한 레포가 낫다는 판단으로 하루 만에 되돌렸다.
- **클로드 앱 커넥터(MCP 서버) 제거.** 폰에서 클로드에 말할 일이 없다. 폰은 웹앱, 클로드는 코드 세션의 ledger 스킬.
  커넥터에만 있던 이벤트 기록은 `logEvent` 로 꺼내 `/api/events?log=` 로 열고 `ledger.py event` 가 부른다.
  커넥터 스키마 캐시를 막던 잠금 파일·실서버 대조·배포 스크립트(572줄)도 같이 사라졌다.
- **채점 실패한 날의 이벤트 유실을 고쳤다.** 서버가 넘기는 순간 '알림 보냄'을 찍어서, 맥에서 채점이 실패하면 다시 안 왔다.
  이제 grade 행이 붙을 때까지 다시 넘긴다(`toHandOff`). 완료 신호를 따로 만들지 않고 맥이 원래 남기던 grade 행을 썼다.

## 헛디딘 곳

- **Vercel Secret 은 `vercel env pull` 로 가림 값만 온다.** 레포 분리 때 `YOUTUBE_API_KEY`·`YT_HANDLE` 을 새 프로젝트로 못 옮겼다.
  로컬 `.env` 에 없는 값은 사실상 그 프로젝트에 갇혀 있다.
- **`git rm` 뒤 `git commit` 에 `-a` 를 빠뜨려** 파일 삭제만 커밋되고 수정은 작업 트리에 남았다. 배포는 작업 트리 기준이라
  동작은 맞았는데 커밋 이력이 어긋났다. revert 하다가 발견했다.
- **배포 실패를 확인하기 전에 다음 명령을 실행했다.** 옛 서버가 모르는 `log=` 인자를 무시하고 평소 동작(알림 보냄 표시)을 했다.
  그날은 넘길 새 이벤트가 0건이라 피해가 없었다. 배포 결과의 `status` 를 먼저 본다.
- **`vercel --scope` 가 CLI 63 에서 `Not authorized` 를 낸다.** 스크립트 주석은 정반대(빼면 죽는다)를 적고 있었다. `.vercel/project.json` 링크만으로 충분하다.
- **채점 실패 원인이 `Expecting value` 로 가려졌다.** 실제로는 맥 claude CLI 로그인 만료(CLI 업데이트 직후). 에러 문장을 JSON 으로
  파싱하다 생긴 메시지였다. 이제 `is_error` 면 그 문장을 그대로 로그에 남긴다. 데스크톱 앱 로그인은 CLI 와 공유되지 않아
  `claude auth login` 을 따로 해야 했다.
- **npm 10.9 의 `edgesOut` 오류**(분리 레포에서만). `legacy-peer-deps` 로 피했다. 지금 레포에는 해당 없음.
