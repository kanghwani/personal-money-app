# 재정 코치

숫자는 가계부 시트(ledger 스킬)가 원본, **규칙·결정·할 일·리뷰는 노션 「재정 코치」**가 원본이다.
메모리에는 포인터만 둔다 — 결정 내용을 메모리에 복제하지 않는다.

- 노션 페이지: https://app.notion.com/p/3ec7fea9f7d581aba070c8675f98a25a (id `3ec7fea9-f7d5-81ab-a070-c8675f98a25a`)
- 가계부: `python3 /Users/hwan/dev/paused/money-app/.claude/skills/ledger/ledger.py <명령>` (명령은 ledger 스킬 참고)

## A. 세션 시작

1. 노션 페이지를 fetch → 「가계부 기록 규칙」「형 가게 장부 관리」「확인할 일」을 머리에 넣는다.
2. 사용자가 꺼낸 주제와 걸리는 미완료 할 일이 있으면 한 줄로 같이 짚는다.

## B. 월 결산 (매달 초, "N월 정리")

1. `check` → 미분류·오분류를 **묻지 않고 고친다**(카테고리·서브·고정/변동·결제수단). 금액 변경·삭제만 확인.
2. `month YYYY-MM` 의 전체 거래를 덤프해 오분류를 눈으로 훑는다(쿠팡 잡화가 식비, 사료가 구독 등).
3. **수입 입력** — 사용자가 준 플랫폼 정산을 플랫폼별 1행·말일 날짜로 `add "+금액 메모 계좌이체 M/D"`.
   서버 파서가 지출 카테고리를 붙이므로 반드시 `edit <id> cat=수입 sub=부수입` 으로 교정. 이미 있는 고정 수입(양도대금 등)은 중복 입력 금지.
4. **카드 이용내역 대조**(사용자가 붙여넣으면) — 금액 일치 + 날짜 ±7일로 매칭하는 스크립트를 scratchpad에 만들어 돌린다. 합계 검증(`assert`)을 넣는다.
   - 카드에만 있는 것 → 내 가계부·가게 장부 둘 다 대조 후 남은 것만 "내 것/형 것" 질문
   - 내 가계부와 금액·날짜·결제수단이 다르면 카드 기준으로 고친다(금액은 확인 후)
5. **형 정산**(가게 장부를 주면) — 가게 장부는 **내 가계부에 절대 넣지 않는다**.
   받을 돈 = 가게 장부의 내 명의 카드 결제분 + 4대보험 형 몫(현재 월 168,640) − 가게 계좌에서 내 카드로 선결제한 금액.
   형 장부에 넣을 줄은 시트 열 순서(날짜·항목·구분·세부구분·구매처·품목·용도·금액·결제수단·결제카드명의)로 TSV를 만들어 `pbcopy`. 금액은 ₩ 없이 숫자.
   받았다고 하면 해당 분담 건을 `settle <id8>`.
6. `month YYYY-MM` 로 최종 숫자를 뽑아 C 단계의 월간 리뷰에 쓴다.

## C. 마무리 — 노션 갱신 ("정리해서 남겨줘", 세션 끝)

노션 페이지를 fetch 한 뒤 **해당 섹션만** `update_content` 로 고친다(전체 교체는 구조를 바꿀 때만).

| 섹션 | 무엇을 |
|---|---|
| 1. 현재 상황 | 기준일, 목표, 지난달 결과, 부채표·4대보험표 변동 |
| 2. 가계부 기록 규칙 | 오늘 새로 생긴 기록 규칙(예: 할부는 총액 1행) |
| 3. 형 가게 장부 관리 | 정산 공식·대조 절차가 바뀌었을 때만 |
| 4. 결정 로그 | 날짜 멘션 + **결정** — 이유. 숫자가 있으면 공식째로 |
| 5. 확인할 일 | 끝난 건 `[x]`(결과 한 줄), 새 할 일 추가. 미완료가 위 |
| 7. 월간 리뷰 | `## YYYY-MM` — 수입(목표 대비 %)·지출 구성·변동 추세·일회성·정리한 것 |

규칙:
- 금액은 천 단위 콤마. 추정치는 "약", 미확인은 "미확인"이라고 쓴다.
- 사용자에게는 무엇을 바꿨는지 3~5줄로만 보고하고 페이지 링크를 준다.
- 메모리에는 새 사실을 쓰지 않는다. 노션에 없는 **작업 방식 피드백**만 메모리에.
